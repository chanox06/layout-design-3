Kids-R-Kreative Homepage Package
================================

Files:
- index.html
- style.css
- assets/

Open index.html in a browser.

Features:
- Fully responsive design with mobile navigation toggle
- Decorative animated background (floating blobs & twinkling stars)
- Google Fonts (Baloo 2 + Nunito) for a playful, kid-friendly look
- Interactive hover effects on cards, buttons, and gallery items
- Real Google Maps embed (iframe) for the location
- Gallery with hover captions and zoom effects
- Animated hero stickers and floating decorative elements
- SEO-optimized title/meta targeting "Daycare & VPK in Mangonia Park, FL"
- LocalBusiness/ChildCare schema markup (JSON-LD) with NAP, hours, and rating
- FAQPage schema markup for local search visibility
- Google review rating badge and rating summary for social proof
- FAQ section with accordion-style expandable answers
- Consistent NAP (Name/Address/Phone) across header, contact, and footer
- Autoplay hero video (banner-video.mp4) with image poster fallback


Notes:
- The client-provided logo is included as assets/kids-r-kreative-logo.png.
- Faculty uses neutral placeholders because no verified staff photos were supplied.
- The newsletter form is front-end demo only.
- The map is embedded via Google Maps iframe using the address:
  4480 S Tiffany Dr, Mangonia Park, FL 33407
- Phone number is clickable via tel: link in the footer.
